## 项目简介

本项目由中国药科大学中药学院**组分结构创新中药实验室**研发，整合国家发布的 **106 种食药物质目录**资源，深度融合**中医传统理论**（四气五味、性味归经、君臣佐使）与现代分子网络药理学方法，为高端人群提供**"一人一方"**的精准功能食品组方设计服务。

**核心定位：**
- **高端人群精准调理**：基于用户证型（气虚证、阴虚证等）与体质（九种体质辨识），实现个性化组方推荐
- **中医传统元素融合**：四气五味、归经、君臣佐使配伍分析，体现中医药文化深厚底蕴
- **功能食品开发场景**：严格遵循国家食药物质管理规范，支撑从原料到产品的全链条研发
- **多维可配置评分模型**：功能靶点覆盖率 / 网络拓扑 / ADME / 协同性 / 安全性 / 口感 / 气味 / 颜色 / 营养，权重基于随机森林模型训练得到（准确率 98.46%，AUC 0.9993）
- 服务于高校科研、课题组汇报、产学研合作展示等学术用途
- 为后续接入后端数据库、AI 组方模型预留标准化接口

## 平台功能模块

### 1. 食药物质基本信息
- 收录 106 种国家食药物质目录品种
- **翻页式详情浏览**：点击卡片后支持左右翻页浏览，键盘 ← → 键快捷切换
- 每味物质展示：**高清图片 + 拉丁学名 + 四气五味 + 归经 + 性状 + 功能主治**
- 详情页分 Tab：**基本信息 / 传统属性 / 现代研究 / 产品形态**
- 产品形态推荐：基于物质特性自动推荐饮片、粉末、袋泡茶、膏方、胶囊等开发方向
- 潜在功能标签：免疫调节、血糖调节、抗氧化、睡眠改善等智能标签

### 2. 功能食品组方设计（一人一方）
- **体质辨证输入**：疾病/功能需求 + 证型（气虚/阴虚/湿热等）+ 体质（九种体质）三维输入
- **固定处方生成**：基于疾病+证型+体质的哈希种子，生成 **10 组处方**，按总分排序后展示 **Top3**，保证结果可复现
- **君臣佐使方解分析**：参考《方剂学》教材体例，自动生成【功用】【主治】【方解】【配伍特点】【使用注意】【方歌】六大要素
  - 君药：基于功能主治匹配度 + 适宜证型/体质匹配度 + 性味强度综合评分，得分最高者任君药
  - 臣药：次高得分者，自动判断辅助君药或兼顾兼证
  - 佐药：细分为佐助、佐制、反佐
  - 使药：甘草优先为调和药；归经涉及脾胃者为引经药
- **剂型联动剂量换算**：支持汤剂、丸剂、散剂、膏方、袋泡茶、胶囊、颗粒剂 7 种剂型
  - 各剂型有独立剂量系数（丸剂 0.6、散剂 0.5、膏方 0.8、胶囊 0.4 等）
  - 处方中每味药实时显示当前剂型的剂量范围
- **虚拟筛选子模块**：对标 TCMSP 9.0.1 的 ADME 参数预筛选（OB、DL、MW、LogP、TPSA 等）
- **多维可配置权重模型**（基于随机森林训练）：
  | 维度 | 权重 | 调整说明 |
  |---|---|---|
  | 功能靶点覆盖率 | **23%** | 核心药效维度 |
  | 网络拓扑重要性 | **14%** | 专家处方显著依赖高频核心药物 |
  | ADME 成药性 | **10%** | 保证可食用性 |
  | 成分协同性 | **11%** | 配伍理论核心 |
  | 安全性与配伍禁忌 | **15%** | 食药底线，文献强调"毒副作用最小" |
  | 口感 | **10%** | 食品属性 |
  | 气味 | **6%** | 食品属性 |
  | 颜色 | **5%** | 食品属性 |
  | 营养 | **7%** | 辅助属性 |
  - 用户可通过滑块实时调节各维度权重，系统自动归一化
  - 权重基于 324 组专家处方（108 种适应症 × 3 个推荐处方）训练得到

### 3. 潜在应用数据挖掘（重构版）
- **双向检索**：
  - **物质名称 → 应用场景**：输入"薄荷"，系统仅在 `herbs` 字段中搜索，返回薄荷的所有应用场景及记载依据
  - **应用场景 → 食药物质**：输入"erectile dysfunction"，系统仅在 `title`/`desc`/`classical_text` 中搜索，返回涉及该场景的所有食药物质
- **严格字段级筛选**：按搜索类型严格限制匹配字段，避免结果泛滥（如搜索"牙膏"不会误匹配 authors/source 字段）
- **内置筛选栏**：
  - 物质搜索结果中，自动提取所有应用场景关键词作为筛选标签
  - 应用搜索结果中，自动提取所有食药物质名称作为筛选标签
- **文献类型过滤**：全部 / 中文期刊 / 英文期刊 / 古籍文献 / 其他
- **排序方式**：最佳匹配 / 发表时间（新→旧/旧→新）/ 第一作者
- **每页条数**：10 / 20 / 50 / 100 / 200
- **结果导出**：支持勾选后导出为 CSV（含标题、作者、来源、年份、文献类型、涉及物质、摘要、古籍原文、白话译文）
- 模糊检索、错字纠正、多语言翻译
- 古籍文献特殊展示：古籍原文 + 白话译文

### 4. 感官预测及营养评估
- 口感、气味、颜色三维感官预测（基于电子舌 / 电子鼻 / 电子眼实测数据）
- 营养价值加权评估（基于 106 种物质营养物质检测数据）
- **剂型偏好联动**：加载组方时同步显示当前评估剂型
- **推荐产品形态**：基于组方中各物质的产品形态交集，智能推荐最终开发剂型

## 传统中医理论支撑

本平台在组方设计中深度融合以下中医核心概念：

- **四气五味**：每味物质标注寒、热、温、凉、平（四气）与辛、甘、酸、苦、咸（五味），指导组方寒热平衡
- **性味归经**：明确每味物质归属的脏腑经络，确保组方靶点精准
- **证型辨证**：平和证、气虚证、血虚证、阴虚证、阳虚证、痰湿证、湿热证、血瘀证、气滞证
- **九种体质**：平和质、气虚质、阳虚质、阴虚质、痰湿质、湿热质、血瘀质、气郁质、特禀质
- **君臣佐使**：方解分析自动识别君药（主药）、臣药（辅药）、佐使药（调和/引经药），参考《方剂学》教材体例
- **配伍禁忌**：基于性味归经与功能主治，自动提示寒热偏颇与禁忌人群

## 技术架构

- **前端**：原生 HTML5 + CSS3 + JavaScript（ES5/ES6）
- **样式**：CSS Variables 主题 + Flex/Grid 响应式布局
- **数据**：前端 JSON（data.js、data/substances_full.js、data/dosage_by_form.js、data/literature_full.js、data/ancient_literature.js）
- **权重模型**：随机森林分类器（scikit-learn），基于 324 组专家处方训练
- **部署**：GitHub Pages（自动 HTTPS、CI/CD）

## 重要文件说明

| 文件 | 作用 |
|------|------|
| `website/index.html` | 主 SPA 入口（~1585行），包含 CSS、HTML 结构、基础 JS |
